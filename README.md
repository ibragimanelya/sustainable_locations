# IbraPloe - Sustainable Locations 🌍
Front-End Development Projekt SoSe2025
Ein Semesterprojekt im Rahmen des Front-End Development Labs an der HTW Berlin. Ziel ist die Modernisierung einer bestehenden Single Page Application (SPA) mit React und TypeScript. Die App verwaltet „unsustainable locations“ und bietet zwei Benutzerrollen: admina (mit vollen CRUD-Rechten) und normalo (read-only).
Tech Stack:
    - Frontend: React + TypeScript
    - Backend: Express (Node.js) oder Wahl
    - Datenbank: MongoDB oder Wahl
